# 🧮 Modern Glass Calculator

A stylish and responsive calculator web application built using **HTML, CSS, and JavaScript**. It features a colorful animated gradient background, glassmorphism UI, smooth animations, and a personalized developer profile section.

## 🚀 Features

- 🧮 Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- 📊 Percentage calculations
- ⌫ Delete and Clear functionality
- ⌨️ Keyboard support
- 🎨 Colorful animated gradient background
- 💎 Modern glassmorphism design
- 🌈 Neon glowing profile photo frame
- ✨ Smooth hover and click animations
- 📱 Fully responsive design
- 👨‍💻 Personalized developer profile section

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, animations, gradients, and glassmorphism effects
- **JavaScript** – Calculator functionality and keyboard interactions

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/mohitkpani/simple-calculator.git
```

### 2. Navigate to the Project Folder

```bash
cd simple-calculator
```

### 3. Run the Application

Open `index.html` in your browser.

No additional dependencies or installations are required.
